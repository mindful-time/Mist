# Circular native mist

`mist-orb-v1.png` is the transparent native mist master. `mist-orb-512-v1.png`
is its mechanically resized 512-pixel application icon. Both retain alpha;
neither includes a wordmark or a background. The website keeps its own wider
mist field unchanged.

Generated with the built-in image-generation tool, using the supplied cloud
reference for volume and `mist-field-alpha-v1.webp` for fine vapor texture.
Prompt: centered circular silver-white mist, layered translucent volume, fine
flowing filaments, soft irregular evaporating edges, genuine transparent alpha;
no ring, hard outline, glass sphere, text, sparkles, or background.

The desktop renderer combines the master with independently moving wisps from
the website texture. Voice identity changes tint, texture sampling, and motion.
OS application icons are static; the in-app mist and voice swatches are animated.
